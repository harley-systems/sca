The <ubuntu_version_id> parameter is optional. The only supported, and default,
ubuntu version id is @@@UBUNTU VERSION ID@@@. Its form is "<major>.<minor>-<release_name>".
The latest point release of this version is downloaded and checked against the
published SHA256SUMS, after checking its signature. Any other ubuntu version id
is rejected.
